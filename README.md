# CourseCrafter

## AI-Powered Personalized Learning Platform

CourseCrafter is an AI-powered personalized learning platform designed to provide students with structured and adaptive learning experiences.

## Objectives

- Generate personalized courses using Generative AI
- Provide structured chapters and learning content
- Recommend relevant educational videos
- Track learner progress
- Analyze quiz performance
- Provide adaptive learning recommendations

## Technology Stack

- Next.js
- React
- Tailwind CSS
- Google Gemini
- PostgreSQL / Neon
- Drizzle ORM
- Clerk
- YouTube Data API

## Research Focus

The research component focuses on performance-based adaptive learning and evaluates whether personalized recommendations can improve learning outcomes and recommendation relevance compared with a fixed learning path.
